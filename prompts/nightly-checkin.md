# 每晚確認：排程指令範本

> 給 AI：把 `{{ }}` 換成使用者的設定，整段當作排程的指令內容。
> 排程如果是「回到原本的對話」執行，可以直接用；如果是「每次開新對話」，要在開頭補上使用者的背景（目標、菜單頁面連結）。

---

【每晚 {{CHECKIN_TIME}} 飲食與運動確認】

1. 查 Notion「飲食紀錄」（{{FOOD_DB}}）和「運動紀錄」（{{WORKOUT_DB}}）今天（{{TIMEZONE}}）的資料列。
2. 讀「一週菜單」（{{MENU_PAGE}}），找出今天的預定菜單和運動安排：{{WEEKLY_WORKOUT_PLAN}}。
3. 用選項卡片確認，**只問還沒記錄的項目**，已確認的跳過：
   - 第一輪：早餐、午餐、點心、晚餐。
     - 已記錄的餐：第一個選項是已記錄的內容，標「（已記錄）」。
     - 沒記錄的餐：第一個選項是菜單上的內容，標「（菜單預設）」。
     - 其他選項放常見替代：{{COMMON_ALTERNATIVES}}、沒吃。使用者可以自己打字。
   - 第二輪：今天的運動（可複選，第一個選項是計畫預設），以及加餐或宵夜。
4. 依回答寫入或更新 Notion：
   - 飲食：每餐一筆，填餐別、內容、熱量、蛋白質（估計），來源＝菜單預設或晚間補記，狀態＝已確認或沒吃。
   - 運動：每種一筆，類型用 健身房／游泳／教練課／跑步／走路／伸展／其他／休息；休息日也記一筆「休息」。
   - 已存在的列用更新，**不要重複新增**。
5. 最後用小表格回報今天合計，對照目標：
   - 休息日 {{KCAL_REST}} kcal、運動日 {{KCAL_TRAIN}} kcal、蛋白質 {{PROTEIN_TARGET}} g 以上
   - 給一句明天可以怎麼調整，不要說教。
   - 備註提到疼痛或不舒服，照 safety.md §4 判斷是否要建議就醫。

使用者沒有回應時，不要重複追問，也**不要**自行把預設內容寫成已確認。

## 可替換的欄位

| 欄位 | 例子 |
|---|---|
| `{{CHECKIN_TIME}}` | 21:55 |
| `{{TIMEZONE}}` | 台灣時間（Asia/Taipei） |
| `{{FOOD_DB}}`、`{{WORKOUT_DB}}` | Notion 資料庫的 URL 或 ID |
| `{{MENU_PAGE}}` | 一週菜單頁面的 URL |
| `{{WEEKLY_WORKOUT_PLAN}}` | 一休息、二健身房、三健身房＋游泳、四休息、五休息、六教練課、日健身房 |
| `{{COMMON_ALTERNATIVES}}` | 另一款便當、超商、家人煮、速食 |
| `{{KCAL_REST}}`、`{{KCAL_TRAIN}}` | 1,850–2,000、2,100–2,300 |
| `{{PROTEIN_TARGET}}` | 110 |
