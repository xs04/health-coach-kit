# 吉祥物

週報上有兩個吉祥物，都是**配角**：

| 位置 | 符號 | 畫布 | 內容 |
|---|---|---|---|
| 頁首右側，坐在「這一週」表格的上緣 | `#dogLift` | `viewBox="0 0 300 330"` | 全身、做運動的姿勢（預設是舉啞鈴）。底部 y≈318 畫一個淡淡的橢圓陰影當地面 |
| 「本週檢討」卡片右側 | `#dogPeek` | `viewBox="0 0 160 140"` | 只露出頭和兩隻前腳，像趴在桌邊偷看。前腳中心大約在 y≈118 |

預設吉祥物是**伯恩山犬**，只是範例，使用者可以換成自己想要的。

## 跟使用者決定吉祥物（AI 照這個流程做）

1. 先給使用者看預設的範例圖（`preview.png`），問想要什麼：
   - 用預設的伯恩山
   - 自己的寵物：**請使用者拍照上傳**，你照特徵畫成插畫（毛色、花紋、耳朵形狀、臉部特徵）
   - 喜歡的動物或角色：用文字描述（不要畫有版權的角色，例如卡通人物；改畫「有類似氣質的原創角色」）
   - 不要吉祥物
2. 畫好兩個姿勢之後，**用範例資料產生一張週報給使用者看**，問：「這樣可以嗎？想調整哪裡？」
3. 依回饋修改，直到使用者說可以。**沒確認之前，不要存成正式設定。**
4. 確認後，把最終的 SVG 存到使用者的紀錄位置（Notion「週報設定」頁面，見 [notion/schema.md](../notion/schema.md)），之後每週產生週報時讀出來用。

## 畫法規格

- **扁平、圓潤**：用 ellipse、rect（加 rx 圓角）、path，線條末端圓頭
- **顏色**：4–6 種就好，主色取自動物本身；臉頰可以加一點粉紅腮紅（透明度 .5 左右）
- **表情**：眼睛有白色反光點，嘴巴微笑
- **不要**：文字、外部圖片、`<script>`、事件屬性、`<foreignObject>`（範本會自動移除這些）
- 兩個姿勢的頭部最好畫成一樣，讓使用者認得出是同一隻
- 照片只用來參考特徵，**不要把照片本身放進週報**

## 資料格式

在週報 JSON 加上 `mascot`：

```jsonc
// 省略：用預設伯恩山
"mascot": "none"                                  // 不放吉祥物
"mascot": {
  "lift": "<g>…全身運動姿勢的 SVG 元素…</g>",       // 300×330 座標
  "peek": "<g>…探頭姿勢的 SVG 元素…</g>"            // 160×140 座標
}
```

只給 `lift` 或只給 `peek` 也可以，沒給的那個會維持預設。
