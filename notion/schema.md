# Notion 結構

> 給 AI：照這份定義建立。欄位名稱請保持一致，因為排程指令和週報都靠這些名稱讀資料。
> 如果你的平台用 SQL DDL 建資料庫（例如 Claude 的 Notion 連線），可以直接用下方的 DDL。

## 母頁面：身體調整計畫

頁面內容寫一段說明：這些資料庫的用途，以及「熱量、蛋白質為估計值」。

## 1. 飲食紀錄（每餐一筆）

| 欄位 | 類型 | 選項或說明 |
|---|---|---|
| 名稱 | 標題 | 例如「午餐｜雞腿便當」 |
| 日期 | 日期 | |
| 餐別 | 單選 | 早餐、午餐、點心、晚餐、加餐、宵夜 |
| 內容 | 文字 | |
| 熱量 | 數字 | kcal，估計值 |
| 蛋白質 | 數字 | g，估計值 |
| 來源 | 單選 | 即時紀錄、照片、菜單預設、晚間補記 |
| 狀態 | 單選 | 已確認、待確認、沒吃 |
| 與菜單相同 | 勾選 | |
| 備註 | 文字 | |

```sql
CREATE TABLE ("名稱" TITLE, "日期" DATE, "餐別" SELECT('早餐':yellow, '午餐':orange, '點心':pink, '晚餐':blue, '加餐':green, '宵夜':purple), "內容" RICH_TEXT, "熱量" NUMBER, "蛋白質" NUMBER, "來源" SELECT('即時紀錄':green, '照片':blue, '菜單預設':gray, '晚間補記':orange), "狀態" SELECT('已確認':green, '待確認':yellow, '沒吃':gray), "與菜單相同" CHECKBOX, "備註" RICH_TEXT)
```

## 2. 運動紀錄（每種運動一筆，休息日也記一筆「休息」）

| 欄位 | 類型 | 選項或說明 |
|---|---|---|
| 名稱 | 標題 | |
| 日期 | 日期 | |
| 類型 | 單選 | 健身房、游泳、教練課、跑步、走路、伸展、其他、休息 |
| 時間 | 數字 | 分鐘 |
| 強度 | 單選 | 輕鬆、中等、吃力 |
| 與計畫相同 | 勾選 | |
| 備註 | 文字 | 練了哪些部位、哪裡不舒服 |

```sql
CREATE TABLE ("名稱" TITLE, "日期" DATE, "類型" SELECT('健身房':blue, '游泳':green, '教練課':purple, '跑步':red, '走路':yellow, '伸展':pink, '其他':gray, '休息':default), "時間" NUMBER, "強度" SELECT('輕鬆':green, '中等':yellow, '吃力':red), "與計畫相同" CHECKBOX, "備註" RICH_TEXT)
```

> 週報圖示的名稱對照：健身房→健身，其餘同名。

## 3. 身體紀錄（每次量測一筆）

| 欄位 | 類型 | 說明 |
|---|---|---|
| 名稱 | 標題 | 例如「InBody 起始點」「每週腰圍」 |
| 日期 | 日期 | |
| 類型 | 單選 | InBody、每週量測 |
| 體重 | 數字 | kg |
| 骨骼肌重 | 數字 | kg |
| 體脂肪重 | 數字 | kg |
| 體脂率 | 數字 | % |
| 腰圍 | 數字 | cm |
| 備註 | 文字 | |

```sql
CREATE TABLE ("名稱" TITLE, "日期" DATE, "類型" SELECT('InBody':blue, '每週量測':green), "體重" NUMBER, "骨骼肌重" NUMBER, "體脂肪重" NUMBER, "體脂率" NUMBER, "腰圍" NUMBER, "備註" RICH_TEXT)
```

## 4. 子頁面：一週菜單

每天一個可以收合的區塊（toggle heading），裡面放表格：餐別、吃什麼、kcal、蛋白質，最後一列是合計。
頁首放一週總覽：運動、晚餐安排、每日熱量、蛋白質。

## 5. 子頁面：週報設定

存放使用者確認過的週報設定，每週產生週報時讀出來：

- **吉祥物**：一個 code block（語言選 JSON），內容是 `{"lift": "…", "peek": "…"}` 或 `"none"`；用預設伯恩山就寫 `"default"`
- **稱呼**：週報上要不要放名字或暱稱

## 沒有 Notion 的時候

1. 先說明連接 Notion 的好處：紀錄會保存下來、手機上隨時查得到、週報可以自動讀資料。
2. 使用者仍然不想接，或平台沒有 Notion 連線（例如 Gemini App）：改用 **Google 試算表**，建三個工作表，欄位名稱和上面完全相同；或照平台文件（platforms/）的 CSV 做法。
3. 週報只需要「每天的運動、三餐、熱量、蛋白質」和「最新腰圍或體重」，不管資料存在哪裡，組出 weekly-card 的 JSON 就能產圖。
4. 「週報設定」（吉祥物 SVG）沒有 Notion 時，存在平台的專案說明、Gem 指示或知識檔案裡。
