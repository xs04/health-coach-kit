# ChatGPT 的設定方式

> ⚠️ **未實際測試**。這份是依照 ChatGPT 一般的功能撰寫的，實際能做到的程度會依方案、地區和功能更新而不同。
> 所以每個步驟都附上「做不到時」的替代做法。設定時請 ChatGPT 先照 AGENTS.md 階段 0 逐項確認自己的能力，並如實告訴使用者。

## 使用者要先準備

| 項目 | 說明 |
|---|---|
| 讓 ChatGPT 讀到這個 repo | 先照 README 的做法**貼網址**。讀不到時：有 GitHub 連線就附加 repo；再不行就下載 ZIP，把 `AGENTS.md`、`safety.md`、`onboarding/`、`notion/`、`prompts/`、`platforms/chatgpt.md`、`weekly-card/` 上傳 |
| 建議使用「專案（Project）」 | 想長期使用的話，把上面那些檔案放進專案的檔案區，專案說明寫：「照 AGENTS.md 和 safety.md 協助我」。之後所有對話都在這個專案裡進行，ChatGPT 比較不會忘記設定 |
| Notion 連線 | 如果你的方案有 Notion 連線（Connectors），先連上 |

## 開始

貼上 README「怎麼開始」的那段話；如果用專案，就在專案裡開對話，輸入「照 AGENTS.md 幫我設定」。

## 各階段在 ChatGPT 上怎麼做

| 階段 | 預期做法 | 做不到時 |
|---|---|---|
| 問卷 | 用編號選項，使用者回覆編號 | — |
| 建 Notion | 用 Notion 連線建立資料庫 | 連線只能讀、不能寫時：ChatGPT 給出欄位清單，**使用者自己在 Notion 建立**（約 5 分鐘），或匯入 ChatGPT 產生的 CSV |
| 日常紀錄 | 透過連線寫入 Notion | 不能寫入時：ChatGPT 在對話裡維護當週紀錄表，每晚確認後輸出一行 CSV，使用者貼進 Notion（或每週匯入一次） |
| 每晚確認 | 用「排程任務（Tasks）」每天定時發訊息 | 排程任務不能讀寫 Notion 時：排程只負責提醒，使用者回到專案對話說「開始今晚確認」。完全沒有排程時：用手機鬧鐘 |
| 週報 | 在 Python 環境執行 `python weekly-card/build_html.py data.json weekly.html`，提供 HTML 下載 | 使用者用瀏覽器打開 HTML 後截圖。不能執行程式時：用文字表格呈現 |
| 傳給教練 | 使用者把截圖傳給教練 | — |

## 特別注意

- **不要用圖片生成功能畫週報**：生成的圖片容易把數字和文字畫錯。週報一定要用 `weekly-card/` 的範本，才能保證數字正確。
- **ChatGPT 的 Python 環境通常沒有瀏覽器**，所以 `--png` 可能無法使用，HTML 加截圖是比較可靠的做法。
- **記憶**：重要設定（每日目標、資料庫連結、運動計畫）寫進專案說明，不要只依賴對話記憶。
- 能力檢查的結果要誠實告訴使用者，例如：「我目前沒辦法自動寫入 Notion，改成每晚給你一行 CSV」。
